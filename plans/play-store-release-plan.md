## P0.1 — HTTPS / Domain Setup

**Why:** `lib/core/api_config.dart` requires HTTPS for release mode. Play Store rejects HTTP-only apps.

**Approach:** Domain `nomnom.lk` + Caddy reverse proxy + Let's Encrypt TLS on VPS.

### Tasks:

| # | Task | File | Effort |
|---|------|------|--------|
| 1 | Purchase `nomnom.lk` from `.lk` domain registry | — | 1h |
| 2 | Add DNS A records: `api.nomnom.lk` + `admin.nomnom.lk` → `169.58.79.251` | DNS | 30m |
| 3 | Add Caddy to staging compose for TLS (use existing `deploy/vps/compose.yml` Caddy config as reference) | `deploy/vps/compose.staging.yml` | 1h |
| 4 | Configure Caddyfile: reverse proxy → `backend:8080` and `admin:3000` | `deploy/vps/Caddyfile` | 30m |
| 5 | Close ports 8080, 3000 — route through Caddy on 443 only | UFW on VPS | 10m |
| 6 | Update CI release dart-define to production domain: `API_BASE_URL=https://api.nomnom.lk/api/v1` | `.github/workflows/ci.yml`, `release.yml` | 15m |
| 7 | Update Firebase authorized domains | Firebase Console | 10m |

### Verification:
```bash
curl https://api.nomnom.lk/health    # 200 + {"status":"ok"}
curl https://admin.nomnom.lk/login   # 200 + login page HTML
flutter build appbundle --release --dart-define=API_BASE_URL=https://api.nomnom.lk/api/v1
```

## P0.4 — Crash Reporting (Sentry)

**Why:** Zero production crash visibility. Backend already has `sentry-go`.

**Files to modify:**

| # | File | Change |
|---|------|--------|
| 1 | `pubspec.yaml` | Add `sentry_flutter: ^8.0.0` dependency |
| 2 | `lib/main.dart` | Add `SentryFlutter.init()` before `runApp()` with DSN from dart-define |
| 3 | `lib/core/api_config.dart` | Add `static String get sentryDsn` — from `--dart-define=SENTRY_DSN` |
| 4 | `.github/workflows/release.yml` | Add `--dart-define=SENTRY_DSN=${{ secrets.SENTRY_DSN }}` |
| 5 | GitHub Secrets | Add `SENTRY_DSN` secret |
| 6 | Sentry dashboard | Create new Flutter project, get DSN |

### Example `main.dart` init:

```dart
if (ApiConfig.sentryDsn.isNotEmpty) {
  await SentryFlutter.init((options) {
    options.dsn = ApiConfig.sentryDsn;
    options.environment = ApiConfig.appEnv;
    options.release = ApiConfig.buildSha;
  }, appRunner: () => runApp(NomNomBootstrap(...)));
} else {
  runApp(NomNomBootstrap(...));
}
```
